# مجسّمات محرّر العالم

ضع ملفات `.glb` هنا. المشهد يعمل بلا أي ملف — كل نوع له شكل إجرائي
مبني بنفس لوحة الألوان — فهذه الترقية اختيارية لا شرط للتشغيل.

## كيف تستبدل شكلاً إجرائياً بمجسّم حقيقي

١. ضع الملف هنا، مثلاً `tree_01.glb`.

٢. افتح `client/src/components/world/assets.jsx` وغيّر سطراً واحداً في
   سجلّ `ASSETS`:

```js
tree: { label: 'شجرة', group: 'nature', Proc: Tree, glb: '/assets/models/tree_01.glb' },
```

هذا كل شيء. لا يُلمس منطق المشهد ولا اللوحات ولا الملفات المحفوظة:
عوالم `world.json` القديمة تفتح بالمجسّم الجديد في نفس المواقع.

## ما يحدث تلقائياً

- **التحويل الكرتوني**: `applyToonMaterial` يمرّ على كل شبكة في الملف
  ويستبدل خامتها بـ `MeshToonMaterial` بخريطة تدرّج من أربع درجات
  حادّة، محتفظاً باللون والخريطة الأصليين. لا حاجة لتصدير خامات
  خاصّة من برنامج النمذجة.
- **الظلال**: تُفعَّل على كل شبكة أثناء المرور.
- **السقوط الآمن**: ملف ناقص أو تالف يعود إلى الشكل الإجرائي مع
  تحذير في الطرفية، بدل أن يُفرّغ المشهد.

## شروط تُراعى في الملفات

- **صيغة واحدة**: `.glb` (الملف الثنائي الذي يضمّ كل شيء) لا `.gltf`
  مع ملفات جانبية.
- **المحور**: المجسّم واقف على `y = 0`، ومركزه على `x = z = 0`، وإلا
  ظهر غاطساً في الأرض أو طائراً فوقها.
- **المقياس**: بالأمتار. البيت في المشهد الحالي بعرض ٦ أمتار تقريباً،
  والسيارة بطول ٤٫٣ أمتار — فاجعل مجسّماتك في هذا النطاق.
- **عائلة فنية واحدة**: اخلط حزمة واقعية بأخرى كرتونية فينكسر اتّساق
  المشهد مهما ضبطت الإضاءة. حزم مثل KayKit أو Kenney أو Synty
  متجانسة داخلياً — التزم بواحدة.
- **الحجم**: الملفات تُجلب عند فتح المحرّر. اضغطها بـ
  [gltf-transform](https://gltf-transform.dev) أو Draco قبل الرفع.

## توليد مكوّن React من ملف

إن أردت التحكّم بأجزاء المجسّم كلٌّ على حدة بدل إدراجه كتلةً واحدة:

```bash
npx gltfjsx public/assets/models/tree_01.glb --transform
```

يُخرج مكوّناً جاهزاً تضعه مكان `Proc` في السجلّ.
